# Asisten AI (Android)

Aplikasi chat AI sederhana. Cukup isi API key (Claude, OpenAI, atau Gemini).

## Cara mendapatkan APK (tanpa Android Studio)
1. Buat repositori baru di github.com (boleh private).
2. Unggah semua isi folder ini (termasuk folder `.github`).
3. Buka tab **Actions** → tunggu "Build APK" selesai (±3–5 menit).
4. Klik hasil build → unduh **AsistenAI-apk** (file zip berisi `app-debug.apk`).
5. Pindahkan ke HP, buka, izinkan "Instal dari sumber tidak dikenal".
